# PortfolioWeb-2025

Versión de 2025 de mi portafolio web profesional, desarrollada con React 19 y Create React App. Este repositorio conserva una etapa anterior de mi presentación como desarrollador y complementa el [portafolio actual](https://luanho11.github.io/portfolio-2026/).

## Ejecutar localmente

Se requiere Node.js y npm.

```bash
npm install
npm start
```

Para generar la versión de producción:

```bash
npm run build
```

La interfaz y sus recursos se encuentran en `src/` y `public/`.
